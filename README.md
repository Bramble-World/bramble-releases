# Bramble for macOS — releases

Signed, notarized builds of [Bramble](https://brambleworld.com), and the feed
the app checks for updates. Published automatically by the release workflow in
the (private) app repository; nothing here is edited by hand.

- **Download:** [latest release](https://github.com/Bramble-World/bramble-releases/releases/latest)
- **Update feed:** `https://github.com/Bramble-World/bramble-releases/releases/latest/download/appcast.xml`

Bramble updates itself — there's no need to come back here once it's installed.
